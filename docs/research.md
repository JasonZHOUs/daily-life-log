# 同类产品调研（2026-10-27）

目的：看看做得好的个人日常记录产品在 UI、功能、健康参数、个人发展、日程规划上怎么做，挑出值得我们学的，以及有没有能直接拿来用的开源项目。

## 看过的产品和值得学的点

| 产品 | 类型 | 值得学的点 | 我们怎么用 |
|---|---|---|---|
| MacroFactor | 饮食/体重 | 用“实际摄入 + 体重趋势”反推真实消耗（自适应 TDEE），每周自动调整热量目标；体重趋势线；周/月平均；快速添加；复制整天/整餐 | ✅ 已做：自适应热量估算 + 一键设为目标（Review） |
| Cronometer | 饮食 | 微量营养素很全 | 暂不做（记录负担大） |
| 薄荷健康 / MyFitnessPal | 饮食 | 本地菜品库大、条形码扫描 | 已加约 50 种新加坡/中式菜；条形码留在 backlog |
| Hevy / Strong | 力量训练 | 每个动作记组数×次数×重量；显示“上次做了多少”；自动识别 PR；每周每个肌群的组数 | ✅ 已做：训练记录、上次成绩、PR 标记、每周肌群组数 |
| Daylio | 心情 | 5 档表情一键打分 + 活动，几秒钟完成 | ✅ 已做：心情 5 档、精力 5 档 |
| Bearable | 健康因素 | 睡眠、饮水、精力、症状一起记，看相互影响 | ✅ 已做：睡眠时长、饮水杯数、步数 |
| Exist | 规律发现 | 自动比较“睡够/没睡够时心情差多少”等关联 | ✅ 已做：Review 里的“规律”卡片（并提示：关联≠因果） |
| Gyroscope | 健康仪表盘 | 一页看全身体数据 | 本周概览里加入睡眠、心情、训练组数 |
| Structured / Sunsama | 日程 | 时间轴视图，标出“现在”和下一件事 | ✅ 已做：今日计划高亮“下一项” |
| TickTick | 任务+习惯+番茄钟 | 专注计时与任务在一起 | 已有 10 分钟启动计时 |
| Discy / Notion | Life OS | 习惯→目标→项目连起来 | 下一步候选：目标（如“12 月体重 68 kg”）与每日行动挂钩 |
| Habitica / Finch | 游戏化 | 奖励、宠物 | 不做（容易分心），保留“宽松连续”机制 |

## 开源项目：能不能直接用？

| 项目 | Stars（约） | 是什么 | 适合你吗 |
|---|---|---|---|
| Super Productivity | 23k | 待办 + 时间块 + 计时，本地优先，有网页版 | 可以单独用作任务/时间块工具（直接用官方网页版即可，无需部署） |
| Loop Habit Tracker | 10k | 安卓习惯追踪，评分算法好 | 只有安卓，你用 iPhone，不适合 |
| wger | — | 自托管健身 + 饮食 + 体重（Django） | 需要 Docker 服务器，Vercel 跑不了；功能偏欧美食物，不支持中文菜品 |
| Beaver Habits / Neohabit | 1.8k / 0.3k | 自托管习惯追踪 | 需要服务器，只管习惯 |
| mhabit / Habo | 1.7k / 1.5k | Flutter 习惯 App | 需要自己打包上架 iOS，成本高 |
| Nomie 5 | 0.6k | 万能追踪器 | 已停止维护 |

**结论**：没有一个现成项目同时覆盖你的需求（饮食 + 增肌训练 + 学习/实验时间 + 每日计划 + 中英双语 + 新加坡食物 + iPhone 主屏幕 + 免费部署）。最划算的是继续在我们自己的项目上吸收这些产品的优点。若想要更强的任务管理，可直接用 Super Productivity 网页版作为补充。
